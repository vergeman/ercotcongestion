Hybrid v4: hover a node to see every constraint it belongs to

Every settlement point (grey dot) is hoverable and deduplicated. Because a node belongs to many constraints, hovering opens a popover listing them — sorted by |SF|, tagged source (−) / sink (+). Click a row to isolate that constraint. Hovering a core dot isolates directly. (Overlap is also eased by zoom in the real map.)
